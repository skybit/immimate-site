Help center

Support that starts with the right details.

Most connection issues come down to the server URL, network reachability, or account permissions. Here is the shortest path to a useful answer.

Open a support issue → Privacy policy

Before opening an issue

  1. Confirm that the Immich server URL opens in a browser on the same Mac.
  2. Use the complete server origin, including https:// when TLS is configured.
  3. Check that the Immich account can sign in and that the server is reachable from the current network.
  4. Update ImmiMate and Immich before reporting a compatibility problem.
Please protect your account. Never include passwords, API keys, private server URLs, or personal photos in a support issue. Redact logs before sharing them.

What to include

  • ImmiMate version and macOS version.
  • Immich server version, if known.
  • The screen or action where the problem occurred.
  • A redacted error message and clear steps to reproduce.

Still stuck?

Open an issue with the details above. A short screen recording or a redacted screenshot can help explain a layout or interaction problem, but never upload private media or credentials.
